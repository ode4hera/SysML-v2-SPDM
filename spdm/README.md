# Simulation Process and Data Management Library

This library provides concepts related to Simulation Process & Data Management (SPDM),
which provides mechanisms for managing simulation requests and related data within a large organization.

This library has originally been developed as part of the [ODE4HERA project](https://www.ode4hera.eu/),
however we encourage contributions by anyone!
To contribute, go to:

**https://github.com/ode4hera/SysML-v2-SPDM**

## Example

Refer to the models in the `examples` folder to see how the library can be used.
